# RestoApp

RestoApp — это адаптивный сайт ресторана, разработанный с использованием **HTML**, **CSS** и **JavaScript**.

## Возможности

* Адаптивная верстка для мобильных устройств, планшетов и ПК
* Бургер-меню для мобильной версии
* Каталог блюд
* Иконки, реализованные через SVG Sprite
* Hover-анимации и плавные переходы
* Чистая и семантическая HTML-разметка

## Используемые технологии

* HTML5
* CSS3
* JavaScript (ES6)
* SVG Sprite
* Git & GitHub
